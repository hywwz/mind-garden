# 说一段，整理成任务（1.14.0 试用）

入口在右上角 **＋ 记一段**。可以写文字；安卓也可以录音并在本机整理。

1. 安卓第一次使用，在「本机整理设置」中选择支持音频的 Gemma `.litertlm` 模型文件。Gallery 的模型保存在另一个应用中，心之林无法直接读取；如果没有可选择的文件，可以点「获取模型」进入模型发布页。下载可能需要登录并接受模型发布者的使用条款。
2. 点「开始录音」。可以暂停、继续；切到后台会暂停，录音留在手机上。不会因为停顿就自动提交。单段最长十分钟，建议先用短段。
3. 点「结束并转文字」，检查或修改文字，再点「整理一下」。也可以直接输入文字整理。
4. 预览里核对任务与灵感。日期、时长和开始条件在「调整」里修改，原话可以展开查看。
5. 最后点「确认收下」。今天的进入今天，明天或其他日期的进入相应日期，没有日期的进入「今天 → 待安排」。暂时想做的可以收为灵感；备注保存在任务来源中。

「建议时间」只处理已经选日期、已填时长的任务，绕开已有具体时间；有未落实的开始条件或前置任务时保持待定。明确说出的时间不会被改动。它是可修改的安排建议，不会自动通知或自动完成任务。

现有末端行动可以在预览中关联；选择修改已有安排时沿用原任务。保存前如果原任务已被完成或改动，会要求重新核对。不会为生活图的上层分支直接创建今日任务。

原话与预览会暂存在当前设备，关闭后可以继续。确认后的任务、灵感和待安排沿用现有保存、备份与可选同步；录音和模型只留在本机，不随记录上传。模型加载较慢或失败时，可以继续手动收下。

## 目前的范围

- 安卓本机模型入口适用于 Android 12 及以上的 arm64 设备；建议使用 16 GB 内存的手机，实际速度和可用性取决于模型、系统与剩余内存。
- Windows、iPad 和单文件网页本次提供文字草稿、手动拆分、确认页与待安排。尚未接入这些平台的本机模型。
- 本版已检查日期、保存规则、重复确认、改期、关联末端、完成记录保留，以及浏览器中输入、草稿恢复与移动排版。**尚未在真实安卓手机上验证录音和模型推理，属于试用功能。** 不把模拟页面或编译成功当成实机验证。

## 实现与学习

- `work/life/capture-core.js`：与界面分离的数据规则，确认后产生新的数据副本。
- `work/life/capture-ui.js` / `capture.css`：入口、草稿、确认卡和待安排。
- `work/android/src/app/mindgarden/personal/VoiceCapture.java`：录音、文件选择与本机请求；没有修改生活记录的权限接口。
- `ModelRunner.java`：复用 Google LiteRT-LM Android 0.19.0，关闭思考输出，限制输出结构。
- `work/android/voice/VoiceDates.kt`：使用固定的北京时间参考解析原话中的时间片段；不接受模型编造的具体日期。
- `work/android/voice/upstream/`：复用 VoiceTodo v0.23.5 的 MIT 日期解析器，保留原文件及许可。

检查：`node work/life/capture-check.cjs`；原生构建后运行 `python tools/check-voice-dates.py`。完整基础检查仍为 `python tools/check.py`。
