# 使用与分享

## 发给姐姐什么

安卓手机只发 **心之林-安卓离线版.apk**；Windows 电脑只发 **心之林-Windows安装.exe**。也可以把本地“发给姐姐”文件夹里的分享包一次发给她，按设备选择安装。

不用发源码、项目 ZIP、你的备份、生活图 JSON、同步连接密钥或安卓签名文件。安装包首次打开为空白，姐姐写的是她自己的内容。

程序没有家庭共享账号。两人分别使用时，各自在设备上保存；需要跨自己的设备同步时，各自创建私有数据仓库。如果连接了同一个私有仓库，就会读写同一套记录。作者个人使用的私人 iPad 网站不作为家人的公共入口；iPad 需要有权限访问的独立 HTTPS 网页入口。

## 第一次使用

1. 写下一个愿望，例如“做出一个小作品”。
2. 逐层拆解，直到出现可以立即开始的一小步。
3. 在末端行动旁点“＋今天”。回到今天，完成后打勾。
4. 有结果时补一句，或者附上文件、作品链接等证据。
5. 日常杂事直接写在今天；突然出现的想法放进灵感。

列表里点箭头展开或收起，点“详情”才会打开说明。右上角可以切换图谱。同一个节点始终使用同一份数据。

## 保存、备份与换设备

本机保存与导出备份是两件事：日常修改自动保存在当前设备，导出备份则是单独保存一份可恢复的副本。删除应用、清理浏览器数据、换设备之前，先在“设置 → 存档”导出完整备份，另存到安全位置。

恢复备份之前先确认内容，避免把别人的记录覆盖到自己设备。跨端同步连接前也应先各自备份，首次合并时看清要使用哪一份。

如果误勾完成，可取消后再真正完成；无需重复添加行动。只有生活图末端行动能加入今天，分支应先继续拆解。

## GitHub 同步

同步是可选功能，没有配置时仍能离线使用。请创建单独的 **Private** 数据仓库，按应用内连接说明，使用仅允许该仓库 Contents 读写的连接密钥。不要将密钥发给别人或写入源码。

各设备各连接一次。联网打开应用时尝试同步，离线修改先留在本机；两边改动冲突时会保留副本并让你选择。密钥失效后需要重新连接。不要把“源码仓库公开”理解成“生活记录也要公开”。
