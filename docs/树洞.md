# 树洞（1.15.0 试用）

右上角点「树洞」。可以一直追加文字和录音；无需先起标题或分类。

- 写完点「留下」。没发送的文字自动暂存，退出后可以接着写。
- 点「录一段」，可以暂停、继续，再点「收下录音」。它作为独立消息追加；点录音播放，长按或点「转文字」查看文字。文字可以纠正，原音保留。
- 点「陪我聊聊」才回应。默认先理解、陪伴，不主动给行动建议；你主动提出要建议时再讨论。
- 点「帮我整理」才整理。区分你说过的内容与可能的理解，允许你纠正。
- 「之前的」打开旧记录，「新一段」另开一个树洞。不会自动创建今日任务。

录音、文字沿用现有存档和同步设置。连接了私有同步仓库时，树洞和录音也在同步范围内；未连接时在当前设备保存。本机模型处理内容，不会自动调用付费或云端 AI 服务。

可以持续追加很多段，不宣称物理上无限存储。安卓单段录音最长约十分钟，可以收下后继续下一段；每个附件遵循原来的 20 MB 上限。浏览器录音需要 HTTPS 或本机预览入口以及麦克风权限。长对话回应参考最近的内容，原话不会因模型上下文限制被删掉。

安卓转文字、陪伴、整理复用已选择的支持音频的 Gemma 模型。Windows、iPad 本次提供记录、浏览器录音、播放与历史；本机 AI 回应仍在安卓端。录音需要先保存到手机附件中才能在安卓转文字。模型加载和处理可能耗时。

已检查文字追加、草稿恢复、测试音频播放、文字展开与修改、保留原音、历史及数据规则；安卓编译和签名检查不代表真实手机上的麦克风、模型效果已经验证。
