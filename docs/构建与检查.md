# 构建与检查

## 网页：建议从这里开始

需要 Python 3.12+ 和 Node.js 22+；推荐 Node.js 24。无需 `npm install`。

在项目根目录运行：

```sh
python tools/build.py
python tools/build.py --web
python tools/check.py
```

第一条生成 `outputs/mind_garden.html`；第二条也生成 PWA 的 `web/dist/`。所有初始页面为空白。构建不会读取作者正在使用的应用存档。

本地预览 PWA：

```sh
python -m http.server 8080 --directory web/dist
```

浏览器打开 `http://localhost:8080`。`localhost` 可用于离线缓存开发；手机或 iPad 的正式主屏幕安装需要可访问的 HTTPS 网站。不要依赖直接打开文件的方式测试 PWA 和同步。

检查覆盖：JS 语法、节点模型及回环校验、虚构网络导入与去重、末端行动资格、同步合并与模拟引擎。真实设备交互、网络、系统文件选择器和安装更新需另行验证。

## 安卓：可选，当前构建器面向 Windows

源代码在 `work/android/src/`，清单在 `AndroidManifest.xml`。现有打包方式直接调用 Java 与安卓工具，不是 Gradle 工程。

需要 JDK 21、Android API jar、AAPT2、R8/D8、zipalign 与 apksigner。当前构建器支持已有 HBuilderX 工具布局；可通过环境变量 `MIND_GARDEN_HBUILDER_PLUGINS` 和 `MIND_GARDEN_JAVA_BIN` 指定对应 plugins 目录与 JDK 的 bin 目录。其他 Android SDK 布局需要调整 `work/android/build.py` 顶部工具路径，不保证任意机器开箱即用。

```sh
python tools/build.py
python tools/fetch-voice-sdk.py
python tools/fetch-voice-build-tools.py
python work/android/build.py
python tools/check-voice-dates.py
```

本机模型运行组件会从 Google Maven 和 Maven Central 下载到忽略的 vendor 目录，模型权重不会自动下载。D8 固定使用 9.5.32，避免旧打包工具不能读取 Kotlin 2.4 元数据。

首次构建会在 `work/android/signing/` 创建自己的签名身份；这些文件已忽略，**必须自己保管**。使用新签名无法覆盖安装作者现有签名的 APK。学习时请在测试设备使用，或修改包名与 provider authority 后独立安装；卸载旧版前先导出备份。

## Windows：可选，当前目标 x64

需要 Windows 的 .NET Framework 4.8 编译工具与 WebView2 SDK。官方 SDK 可从 NuGet 的 `Microsoft.Web.WebView2` 包获得；从包内准备 `Microsoft.Web.WebView2.Core.dll`、`Microsoft.Web.WebView2.Wpf.dll` 和 x64 `WebView2Loader.dll`，放进 `work/windows/vendor/`，或通过 `MIND_GARDEN_WEBVIEW2_SDK` 指定包含这三个文件的目录。运行应用需要 WebView2 Runtime。

```sh
python tools/build.py
python work/windows/build.py
```

生成 `outputs/心之林-Windows安装.exe` 和 `work/windows/build/app/`。安装器安装到当前用户目录，不包含作者的个人存档。不要直接编辑生成的 assets 页面；改源文件后重新构建。

## 版本与发布

目前版本号在安卓清单、Windows C# 与 `browse.js` 等处维护，发布前需要一致核对。构建出来的文件默认不进入 Git，安装包通过 GitHub Releases 分发。

PWA 发布 `web/dist/` 整个目录；内容哈希用于离线缓存更新。仅部署新版 HTML 而遗漏新版 JS/CSS 会导致界面异常。已有私人托管入口不属于公开源码，仓库不包含作者的托管项目身份或访问配置。
