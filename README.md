# 心之林 · Mind Garden

把想要的生活逐层拆成能开始的一小步，再留下做过的结果。

心之林是一个离线优先的个人生活规划工具，包含 **生活图、今天、灵感**。默认以文件夹式层级列表逐层展开，也可以切换到动态图谱。适合自己慢慢整理愿望，而不是一次安排完所有事情。

当前版本：**1.13.3**。核心使用原生 HTML、CSS、JavaScript，无前端框架和第三方 JS 运行依赖；安卓与 Windows 使用轻量原生外壳，iPad 使用可添加到主屏幕的网页。

## 先用起来

- **安卓 / Windows**：从本项目的 [Releases](https://github.com/hywwz/mind-garden/releases) 下载对应安装包。安卓最低 Android 8，电脑版适用于 64 位 Windows 10 / 11，需要 WebView2 运行时。
- **电脑快速体验**：下载源码后运行 `python tools/build.py`，打开生成的 `outputs/mind_garden.html`。这个单文件版适合体验和离线使用，跨端同步请使用原生应用或 PWA。
- **iPad / PWA**：运行 `python tools/build.py --web`，将 `web/dist/` 放到 HTTPS 静态网站，在 Safari 中选择“分享 → 添加到主屏幕”。本地预览见[构建说明](docs/构建与检查.md)。

首次打开为空白。可以自己写愿望，也可以在“设置 → 存档 → 导入生活图”中导入 [练习生活图](examples/练习生活图.json)。它只是虚构练习，不包含作者的生活记录。

## 能做什么

- **逐层探索**：愿望可以继续拆分成多层分支；点箭头展开，完整阅读节点标题，主动点“详情”才打开说明。
- **两种视图**：层级列表便于阅读；图谱支持展开收起、拖动、平移缩放及父子牵引。
- **关联复用**：支持共同上层路径与跨分支关联，减少重复拆解。
- **今天**：只有末端行动能加入今天；可调整顺序、完成或取消完成，并补充结果。日常杂事也可以独立记录。
- **灵感**：记录想法、搜索内容、补充文件和尝试。
- **本机保存**：支持备份恢复。可选连接自己的 GitHub **私有数据仓库**同步记录和附件，独立改动合并，冲突时选择保留哪份。

**本公开仓库存放程序源码；同步数据应放在另外的私有仓库。** 将同一个安装包发给家人不会共享数据；只有连接同一个同步仓库才会同步同一套记录。请不要把个人备份、连接密钥或安卓签名私钥上传到这里。

## 项目怎么读

| 位置 | 内容 |
| --- | --- |
| `work/life/base.html` | 基础页面及早期应用逻辑，是独立构建模板 |
| `work/life/` | 节点模型、层级树、图谱、关联、导入及交互模块 |
| `work/sync/` | 各端共用的同步规则、合并引擎与界面 |
| `web/` | iPad / PWA 的本地存储、GitHub 适配与离线缓存 |
| `work/android/` | 安卓 Java 外壳、布局和打包工具 |
| `work/windows/` | Windows C# / WebView2 外壳、存储和安装器 |
| `tools/` | 统一构建入口与可独立运行的检查 |
| `examples/` | 可导入的虚构练习数据 |
| `docs/` | 使用、架构、构建和学习说明 |

生成的 `outputs/`、`web/dist/`、原生构建目录与本机资料不提交 Git。`work/` 是当前源码所在位置，保留原模块结构，避免为整理目录而改动应用行为。

## 如何学习这个项目

建议从 **运行 → 看懂数据 → 跟踪一个操作 → 修改一个小功能 → 理解同步 → 了解外壳** 的顺序开始。

1. 阅读[给使用者的说明](docs/使用与分享.md)，导入练习文件，实际展开到末端并加入今天。
2. 按[学习路线](docs/学习路线.md)阅读核心文件，做小练习。
3. 对照[架构与数据](docs/架构与数据.md)，理解一个节点如何变成任务与行动记录。
4. 按[构建与检查](docs/构建与检查.md)独立生成网页和运行检查，再考虑原生打包。

这是逐步迭代的个人项目，部分功能通过覆盖早期函数接入，并不是一套已经完成全面重构的教学框架。学习时先顺着一个用户操作阅读，理解真实取舍，再考虑改善结构。

## 检查与已知限制

```sh
python tools/build.py --web
python tools/check.py
```

此前版本已通过实际 Windows 外壳与 Chromium 模拟移动端的交互检查，包括层级展开、末端行动安排、完成保存、模拟同步合并及冲突处理。仓库中的自动检查主要验证数据规则、构建与同步引擎；不能替代真实 iPad/Safari、安卓硬件或真实远程仓库测试。

同步依赖 GitHub 网络可达性、接口限制与连接密钥有效期；打开应用时同步仍可能需要等待。PWA 在后台和关闭时的运行受系统限制。请保留独立备份。
